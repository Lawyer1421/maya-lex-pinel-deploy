# ADR-0003 — Agentes como manifiestos JSON
**Estado:** Aceptado · **Fecha:** 2026-10-25
**Decisión:** Un `agent.json` por agente, validado al cargar y fallando cerrado. JSON (no YAML) para no añadir dependencia.
**Consecuencias:** Permisos revisables en Git; sin comentarios en JSON (la documentación vive en AGENTS.md).
